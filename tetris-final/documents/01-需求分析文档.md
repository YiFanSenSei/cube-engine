## 1. 项目概述

### 1.1 项目背景

本项目是基于经典方块规则开发的现代化桌面游戏，采用 **Electron + C++ Native Addon** 混合架构。核心游戏逻辑全部由 C++ 实现（N-API 封装），前端使用 Canvas 渲染和 Web Audio API 音效，通过 IPC（进程间通信）连接前后端。此外还提供了独立的 C++ HTTP API 服务器，支持远程游戏访问。

### 1.2 项目目标

- 实现功能完整、体验流畅的方块游戏
- 支持 **6 种游戏模式**：闯关模式、人机对战、双人对战、合作模式、挑战模式、建造模式
- 提供丰富的个性化系统：方块皮肤、UI 主题、自定义键位
- 实现完整的账户、成就、商店经济系统
- 通过 C++ 原生模块保证核心运算性能
- 搭建 CI/CD 自动化流水线，保障代码质量

### 1.3 目标用户

| 用户类型 | 说明 |
|---------|------|
| 休闲玩家 | 偶尔游玩，体验经典玩法与创新模式 |
| 硬核玩家 | 挑战高分、研究 AI 策略、冲击成就 |
| 双人玩家 | 本地同屏对战或合作 |
| 开发者（GM） | 管理后台、测试游戏经济平衡 |

| 编号 | 需求 | 指标 |
|------|------|------|
| NFR-01 | 帧率 | 稳定 60 FPS |
| NFR-02 | C++ 运算延迟 | 单次更新 < 1ms |

| NFR-04 | 服务器并发 | 支持至少 100 个并发游戏会话 |
| NFR-05 | 启动时间 | < 3 秒 |

### 3.2 可靠性

| 编号 | 需求 | 描述 |
|------|------|------|
| NFR-06 | 数据持久化 | 所有用户数据保存到 JSON 文件，异常时不会损坏已有数据 |
| NFR-07 | 错误隔离 | C++ 引擎崩溃不应导致整个应用崩溃（try-catch 包裹 IPC） |
| NFR-08 | 输入保护 | 游戏状态异常时键盘输入被安全忽略 |

### 3.3 可维护性

| 编号 | 需求 | 描述 |
|------|------|------|
| NFR-09 | 代码分层 | C++ 核心逻辑与 JS 渲染严格分离 |
| NFR-10 | 单元测试 | C++ 核心引擎覆盖 ~25 个 Google Test 测试用例 |
| NFR-11 | CI/CD | GitLab CI 4 阶段流水线：编译 → 测试 → 代码检查 → 部署 |

### 3.4 安全性

| 编号 | 需求 | 描述 |
|------|------|------|

### 4.2 主要用例描述

**用例 UC-01：进行闯关模式**
- 参与者：玩家
- 前置条件：已登录账户，选择"闯关模式"
- 基本流程：
  1. 游戏初始化，C++ 引擎创建 10×20 棋盘
  2. 方块从顶部下落，玩家通过键盘控制移动/旋转
  3. 消行计分，到达关卡目标分进入下一关（速度递增）
  4. 方块堆至顶部触发 Game Over
  5. 显示本局统计（得分/关卡/消行数）
- 后置条件：游戏数据存入会话，成就系统检查进度

**用例 UC-02：进行建造模式**
- 参与者：玩家
- 前置条件：已登录，选择"建造模式"
- 基本流程：
  1. 随机从 10 种挑战中抽取 5 个作为目标
  2. 玩家使用特殊建造方块（SINGLE/BAR2/BAR3/CORNER 等）进行建造
  3. 完成挑战获得分数 + 连击奖励
  4. 消行倒扣 50 分，方块无法放置时丢弃
  5. 完成所有 5 个挑战后重新抽取
- 后置条件：无 Game Over，可无限进行

## 5. 数据流概述

```
输入层                   处理层                     持久化层
─────────              ──────────                ──────────
键盘事件 ──→  input.js ──→  IPC ──→ main.js ──→ C++ Engine (实时游戏状态)
                                      │                │
                                      ├── 读取状态 ─────┘
                                      │       │
                                      ↓       ↓
                                  game_proxy.js ←── getState()
                                      │
                                      ↓
                            renderer.js → Canvas (60fps 渲染)
                            audio.js → Web Audio API
                            particles.js → Canvas 特效层
                            achievements.js → 进度检查
                                      │
                                      ↓
                                  db:set/db:get ←── data/*.json
```
