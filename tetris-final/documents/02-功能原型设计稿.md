- **布局**：
  - 左侧主棋盘区（10×20 格）
  - 右侧信息面板（Next 预览、得分、消行、等级、关卡目标）
  - 底部操作提示
- **交互要素**：
  - Ghost Piece：半透明方块投影显示落点
  - 消行动画：行闪烁 → 消失 → 上方行下落
  - 连击文字：Combo xN! 浮动显示

- **状态覆盖层**：
  - 暂停：半透明遮罩 + 暂停文字
  - Stage Clear：金色文字 + 下一关倒计时
  - Game Over：红色遮罩 + 统计数据

## 3. 交互设计规范

### 3.1 键盘操作映射

| 模式 | P1 控制 | P2 控制 |
|------|---------|---------|
| 闯关 | A/D 移动, W 旋转, S 软降, F 硬降 | — |
| 人机对战 | 同上 | —（AI 自动） |
| PvP | A/D 移动, W 旋转, S 软降, F 硬降 | ←/→ 移动, ↑ 旋转, ↓ 软降, Space 硬降 |
| 合作 | A/D 移动, W 旋转, S 软降, F 硬降 | ←/→ 移动, ↑ 旋转, ↓ 软降, Space 硬降 |
| 挑战 | 同闯关 | — |
| 建造 | 同闯关 | — |
| 通用 | Esc=暂停, F3=调试, Alt+Enter=全屏 | — |

> 所有按键均可通过设置界面自定义绑定。

### 3.2 触控反馈

| 事件 | 视觉反馈 | 音效 |
|------|---------|------|
| 方块移动 | 方块平滑平移 | 短促"滴"声 |
| 方块旋转 | 方块旋转动画 | 较高音"叮"声 |
| 软降 | 加速下落 | — |
| 硬降 | 瞬间锁定，冲击波特效 | 重击声 |
| 消行（1-3行） | 行闪烁 → 消失 → 粒子爆发 | 上升音调 |
| Tetris（4行） | 金色粒子雨浮动特效 | 高亢长音 |
| 锁定 | 涟漪波纹从锁定点扩散 | 轻微闷响 |
| 关卡达成 | 金色闪烁文字 + 过渡 | 胜利音效 |
| Game Over | 红色遮罩 + 分数统计 | 结束音 |
| 成就达成 | 弹出通知 + 浮动文字 | 特殊成就音效 |

### 3.3 响应式设计

- **窗口尺寸**：860×960 默认，可缩放
- **自适应规则**：
  - 游戏画布根据窗口大小等比缩放
  - 棋盘格大小 = `min(可用宽度/列数, 可用高度/行数)`
  - 信息面板随窗口宽度自动调整位置
- **全屏模式**：Alt+Enter 切换
