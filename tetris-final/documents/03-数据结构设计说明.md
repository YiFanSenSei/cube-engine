## 2. C++ 核心引擎数据结构

### 2.1 TetrisGame 类 — 核心游戏状态机

#### 2.1.1 棋盘状态

```cpp
grid: vector<vector<int>>          // 20×10 二维矩阵
                                   // 0 = 空, 非0 = 已占用

gridNames: vector<string>          // 扁平数组，长度 200 (20×10)
                                   // 每个元素存对应格子的方块名
                                   // (如 "T", "S", "Z", "I", "O", "J", "L")
                                   // 空格子为空字符串
```

- `grid` 做碰撞检测，`gridNames` 做着色渲染
- `gridNames` 用扁平数组（而非二维），方便 IPC 批量序列化
- 坐标转换：`index = row * COLS + col`

#### 2.1.2 活动方块

```
piece: string                      // 当前方块类型 ("T","S","Z","I","O","J","L")
pieceX, pieceY: int                // 左上角棋盘坐标
currentRotation: int               // 旋转状态 (0-3)

currentShape: vector<vector<int>>  // 当前形状矩阵（从 SHAPES 表动态生成）
nextPiece: string                  // 下一个预览方块
```

旋转矩阵：顺时针旋转，`newShape[j][size-1-i] = oldShape[i][j]`。

#### 2.1.3 7-Bag 随机队列

```
bag: vector<string>                // 方块队列
bagIndex: size_t                   // 发牌位置
```

每次需要新方块时检查 bagIndex，超出则生成新洗牌追加到 bag 尾部，保证每 7 个方块中每种形状恰好出现一次。

#### 2.1.4 物理计时器

```
dropCounter: double                // 重力计时 (ms)
dropInterval: double               // 下落间隔 = max(50, 1000 - (level-1) * 85)
lockDelay: double                  // 当前锁定延迟计时 (ms)
lockDelayMax: double               // 锁定延迟上限 = 500ms
lastTime: double                   // 帧时间戳
```

锁定延迟：方块着陆后开启 500ms 窗口，玩家仍可移动/旋转，移动操作**重置**计时器。

#### 2.1.5 计分系统

```
score: int, lines: int             // 当前得分、累计消行
level: int, stage: int             // 等级（速度）、关卡（闯关模式）
```

| 事件 | 分值 |
|------|------|
| 消 1 行 (Single) | 100 × level |
| 消 2 行 (Double) | 300 × level |
| 消 3 行 (Triple) | 500 × level |
| 消 4 行 (Tetris) | 800 × level |
| 软降 | 1/格 |
| 硬降 | 2/格 |
| 建造消行 | -50/行 |

#### 2.1.6 消行与模式标记

```
clearing: bool                     // 消行动画进行中
clearRows: vector<int>             // 消除行索引
clearTimer: double                 // 动画计时器
hasLocked: bool                    // 本帧已锁定标记

gameOver: bool, paused: bool       // 游戏结束、暂停
buildMode: bool, isAI: bool        // 建造模式、AI 模式
difficulty: string                 // "easy"/"medium"/"hard"
```

#### 2.1.7 AI 数据结构

```cpp
aiMoveSteps: vector<string>        // AI 行动队列
aiWaitTimer: double                // 行动间隔计时器

struct AIMove {
    vector<vector<int>> shape;     // 形状矩阵
    int x, y;                      // 放置坐标
    int rot;                       // 旋转次数
    double score;                  // PD 评估分数
};
```

**Pierre Dellacherie 评估**：

| 特征 | 权重 | 说明 |
|------|------|------|
| landingHeight | -4.500158 | 方块中心距底高度 |
| erodedCells | +3.418127 | 消行数 × 接触格数 |
| rowTransitions | -3.217888 | 行内空↔块切换次数和 |
| colTransitions | -9.348695 | 列内空↔块切换次数和 |
| holes | -7.899265 | 被方块覆盖的空格数 |
| wellSum | -3.385597 | 所有列"井"深度和 |

**两阶段策略**：优先筛选能消行的方案（+100/+500/+2000/+5000），若无则走完整评估。

### 2.2 HTTP 服务器数据结构

```cpp
struct GameSession {
    unique_ptr<TetrisGame> game;       // 游戏实例
    string playerName;                 // 玩家名
    int highScore;                     // 最高分
    steady_clock::time_point lastAccessTime;
    bool loggedIn;
};

class GameManager {
    unordered_map<string, shared_ptr<GameSession>> sessions;
    mutex mutex;                       // 线程安全锁
    uint64_t nextId;                   // 会话 ID 生成器
};
```

后台线程定期清理 30 分钟超时的过期会话。

## 3. JavaScript 层数据结构

### 3.1 GameProxy — 游戏状态代理

```javascript
class GameProxy {
    isAI: boolean;

    // 棋盘镜像（C++ 同步）
    grid: Array<Array<number>>         // 20×10, 0=空

    // 计分
    score: number, lines: number
    level: number, gameOver: boolean
    paused: boolean

    // 方块统计
    blockStats: { [pieceName: string]: number }

    // 活动方块
    piece: string | null
    nextPiece: string | null
    currentShape: Array<Array<number>>
    pieceX: number, pieceY: number
    currentRotation: number
    hasLocked: boolean

    // 消行动画
    clearing: boolean
    clearRows: Array<number>
    clearTimer: number

    // 物理
    dropCounter: number, dropInterval: number
    lastTime: number, lockDelay: number
    lockDelayMax: number

    // AI
    aiMoveSteps: Array<string>
    aiWaitTimer: number
    difficulty: string, buildMode: boolean

    // 缓存
    _ghostY: number
    _cachedClearRows: Array<number> | null
    _clearingCounted: boolean
}
```

## 4. JSON 持久化数据结构

文件命名规则：`tetris_{用户名}_{类型}.json`

| 文件 | 作用 | 内容 |
|------|------|------|
| `tetris_users.json` | 用户列表 | `["Alice","Bob",...]` |
| `tetris_current_user.json` | 当前登录 | `"Alice"` |
| `tetris_{user}_achievements.json` | 成就进度 | `{unlocked:[], stats:{...}}` |
| `tetris_{user}_shop.json` | 商店数据 | `{blockSkins:[], uiSkins:[], gold:N, diamond:N}` |
| `tetris_{user}_leaderboard.json` | 排行榜 | `[{score,date}, ...]` |
| `tetris_{user}_brightness.json` | 亮度模式 | `"dark"` |
| `tetris_{user}_theme.json` | UI 主题 | `"ocean"` |
| `tetris_{user}_custom_skin.json` | 当前皮肤 | `"rainbow"` |

### 4.1 成就持久化格式

## 5. 三层数据关系

```
┌───────────────────────────────────────────────────────┐
│                  JSON 持久化层 (data/*.json)            │
│  用户列表 → 成就 → 商店 → 排行榜 → 亮度/主题/皮肤      │
└─────────────────────┬─────────────────────────────────┘
                      │ db:get / db:set (IPC)
┌─────────────────────▼─────────────────────────────────┐
│                内存运行时层 (JS)                        │
│  GameProxy ← syncFromNative() ← nativeAPI.getState()  │
│  gameStats ← 每帧更新 ← achievements 检查引擎           │
│  gameSkins/themes ← account.js 读取/写入                │
└─────────────────────┬─────────────────────────────────┘
                      │ IPC (ipcMain.handle)
┌─────────────────────▼─────────────────────────────────┐
│               C++ 原生引擎层 (addon)                    │
│   games.player (TetrisGame)                            │
│   games.ai    (TetrisGame)                             │
│   grid / gridNames / piece / score / bag / ...        │
└───────────────────────────────────────────────────────┘
```

**数据流（每帧 60fps）：**
1. 键盘事件 → `input.js` → `nativeAPI.move/rotate/hardDrop`
2. `gameLoop` → `nativeAPI.update({game, dt})` → 重力/锁定/AI
3. `syncFromNative()` → `nativeAPI.getState()` → 全量状态写入 GameProxy
4. `renderer.js` 读取 GameProxy → Canvas 渲染
5. `achievements.js` 检查成就 → 完成时写入 JSON
6. `particles.js` + `audio.js` 更新特效/音效
