## 1. 快速开始

### 1.1 运行游戏

**方式一：双击运行**

双击根目录的 `开始游戏.bat` 即可启动。

**方式二：命令行运行**

```bash
npm start
```

### 1.2 启动流程

1. **启动 LOGO** — 显示"703 Studio"品牌动画
2. **账户选择** — 选择已有账户或以游客身份进入
3. **主菜单** — 选择游戏模式或进入设置

### 1.3 系统要求

| 项目 | 最低要求 |
|------|----------|
| 操作系统 | Windows 10/11 |
| CPU | 双核 2.0 GHz |
| 内存 | 4 GB |
| 显卡 | 支持 DirectX 11 |
| 存储 | 500 MB |

## 3. 游戏模式

### 3.1 单人模式

标准方块玩法。随着等级提升，方块下落速度逐渐加快。

- 使用方向键控制方块
- 消除满行获得分数
- 方块堆叠到顶部即游戏结束

### 3.2 双人对战模式

两名玩家在各自棋盘上进行对战：

| 功能 | 说明 |
|------|------|
| **P1 控制** | 方向键（← → ↓ 移动，↑ 旋转） |
| **P2 控制** | A/D 移动，W 旋转，S 速降 |
| **胜负条件** | 一方游戏结束即分出胜负 |
| **骚扰机制** | 消除多行给对方底部增加垃圾行 |

### 3.3 双人合作模式

两名玩家共享一个加宽棋盘（20 列 × 20 行），共同消除方块：

- **P1 控制**：方向键
- **P2 控制**：WASD
- **目标**：合作消除满行，尽可能获得高分
- 一方游戏结束即整体失败

### 3.4 AI 模式

观看 AI 自动玩方块：

- AI 使用 **Pierre Dellacherie 评估算法**
- 支持 P1 (AI) vs P2 (AI) 双人对战
- 可选择不同难度等级
- AI 思考延迟随难度调整

### 3.5 建造模式

自由摆放方块的创意模式：

- 可以在地图任意位置放置方块
- 没有游戏结束判定
- 适合搭建图案和测试
- 可通过设置开启/关闭

### 5.3 状态信息

- **分数** — 当前得分
- **行数** — 已消除的总行数
- **等级** — 当前难度等级（影响下落速度）
- **Hold** — 暂存方块（按 C 键交换）
- **Next** — 预览下一个方块

### 5.4 特效系统

- **消除粒子爆发** — 消除行时的粒子动画
- **冲击波** — 方块落地冲击波效果
- **浮动文字** — 显示连击信息
- **Tetris 金雨** — 四行消除时的金色特效
- **连击 HUD** — 屏幕上方显示连击数
- **锁定涟漪** — 方块锁定时的波纹效果

## 11. AI 模式

### 11.1 AI 算法

AI 使用 **Pierre Dellacherie** 评估函数，综合考虑以下因素：

- 已完成的行数
- 井状区域深度
- 高度加权
- 空洞数量
- 块状程度

### 11.2 难度设置

| 难度 | AI 思考延迟 | 表现 |
|------|-------------|------|
| 简单 | 较慢 | 偶尔失误 |
| 中等 | 适中 | 稳定表现 |
| 困难 | 较快 | 近乎完美 |

### 11.3 AI 对战

在双人模式中选择 AI vs AI，可以观看两个 AI 的对决。

## 13. 常见问题与故障排除

### Q: 游戏启动后黑屏/无法显示

```bash
# 尝试清理缓存后重启
npm start
```

如果问题持续，尝试：
1. 删除 `node_modules` 文件夹，重新运行 `npm install`
2. 确认显卡驱动已更新
3. 在设置中切换亮色/暗色模式

### Q: 账户数据丢失

账户和游戏数据存储在 `data/` 目录。如数据异常：

1. 关闭游戏
2. 备份 `data/` 目录
3. 删除问题数据文件
4. 重新启动游戏

### Q: 自定义按键不生效

1. 进入设置 → 按键设置
2. 确认按键已正确绑定
3. 如有冲突，系统会提示
4. 重启游戏后生效

### Q: C++ 引擎错误

如果出现与 C++ 引擎相关的崩溃：

```bash
# 重新编译原生模块
npx node-gyp rebuild
```

### Q: 游戏卡顿/掉帧

1. 关闭其他占用 GPU 的程序
2. 在设置中关闭粒子特效
3. 降低游戏窗口分辨率
4. 更新显卡驱动

### Q: 如何卸载游戏？

删除整个项目文件夹即可（游戏数据全部存储在本地 `data/` 目录中）。

### A. 文件存储结构

```
tetris-new/
├── data/                          # 游戏数据（JSON 文件）
│   ├── tetris_users.json          # 用户账户数据
│   ├── tetris_current_user.json   # 当前登录用户

├── renderer/                      # 前端界面
├── native/                        # C++ 游戏引擎
└── back_end/                      # 后端 API 服务器
```
